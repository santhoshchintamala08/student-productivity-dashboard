# 📚 Student Productivity Dashboard

A web application built to help students organize their study sessions and track their daily study goals.

## ✨ Features

- ⏱️ Study Timer
- 🎯 Daily Study Goals
- 📊 Study Progress Tracking
- 🌙 Dark Mode
- 💾 Local Storage for saving data
- 📅 Study Planner

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📸 About the Project

This is my first web development project. I built it to practice HTML, CSS, and JavaScript while creating something useful for students.

## 🎯 What I Learned

- Creating web pages with HTML
- Styling pages with CSS
- Adding interactivity using JavaScript
- Saving information using Local Storage
- Publishing a website with GitHub Pages
